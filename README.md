# 🏌️ آکادمی گلف ۱۴۰۵ — داشبورد PRO

داشبورد حرفه‌ای مدیریت آکادمی گلف — کاملاً فارسی، آفلاین و تک‌فایل.

## 🌐 لینک زنده (GitHub Pages)
https://babakmvmv-lab.github.io/golf-academy-pro/

## 🔑 ورود
یوزر و رمز کاربران (مدیر و اعضا) در اولین اجرا ساخته می‌شوند و فقط **به‌صورت محلی** روی دستگاه ذخیره می‌شوند — رمزها **هرگز** روی ابر همگام‌سازی نمی‌شوند.

> یوزر و رمز اعضا از دو جا قابل تغییر است و **دوطرفه همگام** می‌شود:
> «پلن مدیریت ← بازیکنان ← ویرایش» و «پلن مدیریت ← یوزها ← 🔑 یوزر و رمز».
> ⚠️ توصیهٔ امنیتی: بلافاصله بعد از اولین ورود، رمزها را از «پنل مدیریت ← یوزها» تغییر دهید و رمز پیش‌فرض را نگه ندارید.

## ✨ امکانات
- 🎬 **اینتروی سینمایی با صدا** — سوت چوب و ضربهٔ «سوئیت‌اسپات» دقیقاً روی فریم ضربه، و **تشویق جمعیت** وقتی توپ داخل هول می‌افتد (صدا کاملاً محاسباتی/WebAudio است؛ هیچ فایل صوتی و اینترنتی لازم نیست). پنل و لابی بی‌صدا هستند.
- 🛎️ **لابی آکادمی** — رسپشن، تماس با ما، اطلاعات، تقویم و رکورددارها؛ در موبایل تصویر طوری قاب می‌شود که خانم رسپشن وسط کادر باشد و دکمهٔ «ورود اعضا» کوچک و بالای صفحه است.
- ⚙️ **پلن مدیریت (Admin PRO)** — بازیکنان، زمین‌ها، مسابقات، دوره‌ها، نتایج، تقویم، تماس، اطلاعات، یوزها، درخواست سکه، رنک و آواتار، فروشگاه.
- 🪙 **اقتصاد سکه** — درخواست عضو → تأیید مدیر؛ و **سکه‌های قهرمانی کاملاً خودکار**: از روی نتایج فعلی محاسبه می‌شوند (سطح ۱ = ۲۰، سطح ۲ = ۱۵، سطح ۳ = ۱۰). با حذف مسابقه یا تغییر قهرمان، موجودی سکه بلافاصله کم/زیاد می‌شود.
- 🎨 **آواتار و فروشگاه برند** — ۹۳ آیتم با قیمت‌گذاری بر پایهٔ برندهای واقعی پوشاک گلف؛ خرید دائمی است.
- 🏅 **Honor Rank** — ۱۵ سطح و ۵ دیویژن؛ ظاهر آواتار در کل سایت از رنک تبعیت می‌کند و از پنل مدیریت قابل ویرایش است.
- 🛠️ **تنظیمات نمایش** — هر نمودار/بخش (و آنچه اعضا می‌بینند) قابل فعال/غیرفعال کردن است.
- 📅 تقویم شمسی با تعطیلات رسمی ۱۴۰۵ + ورودی تاریخ شمسی در همهٔ فرم‌ها.
- 📊 صفحات تحلیلی، رکوردها، نمایش تلویزیونی و طراحی موبایل‌محور.

## 🗂 ساختار
