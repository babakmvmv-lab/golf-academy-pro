# انتشار اصلاح سقف حجم `ga-sync`

## مشکل و مرز انتشار

کلید `ga_academy` با حجم حدود ۸۲۳ KiB در صف مانده است. سرور قبلی `ga-sync` بدنه‌های با طول بیش از `800_000` را رد می‌کند؛ پنل قبلی نیز محدودیت محافظتی `790000` داشت.

نسخهٔ آمادهٔ جدید، بودجهٔ یکسان **۲٬۰۹۷٬۱۵۲ بایت UTF-8 (۲ MiB)** برای هر درخواست در کلاینت و سرور دارد. قالب دادهٔ `ga_store`، نام کلیدها، مجوزهای دیتابیس و اطلاعات کاربران تغییر نمی‌کنند؛ نه فشرده‌سازی اختصاصی و نه قطعه‌قطعه‌سازی داده در جدول انجام می‌شود.

**پوش‌کردن این فایل در GitHub فقط کد را ذخیره می‌کند؛ تابع زندهٔ Supabase خودکار منتشر نمی‌شود.** اگر سرور هنوز نسخهٔ قبلی باشد، پنل خطای HTTP 413 را نشان می‌دهد و داده را در صف نگه می‌دارد. پس از انتشار سرور، همان صف موجود قابل ارسال است؛ نیازی به پاک‌کردن مرورگر یا واردکردن دوبارهٔ داده نیست.

## انتشار از داشبورد — بدون ارسال هیچ کلیدی در چت

1. داشبورد پروژهٔ `iultwqtzvrysugfxwshw` را باز کنید:
   https://supabase.com/dashboard/project/iultwqtzvrysugfxwshw/functions
2. در **Edge Functions**، تابع موجود **`ga-sync`** را باز کنید و وارد بخش **Code / Edit code** شوید.
3. محتوای `index.ts` تابع را با فایل آمادهٔ این ریپو جایگزین کنید:
   **`supabase/functions/ga-sync/index.ts`**
4. **Deploy updates / Deploy** را بزنید و تا تأیید موفقیت انتشار صبر کنید.
5. تنظیمات احراز هویت/JWT، Secrets، URL پروژه و کلیدها را تغییر ندهید. تابع از متغیرهای سروری موجود استفاده می‌کند؛ هیچ کلید محرمانه‌ای نباید داخل فایل نوشته شود.

این فایل **TypeScript مخصوص Edge Function** است؛ آن را در **SQL Editor** اجرا نکنید. نیازی به ساخت دیتابیس، جدول یا تابع جدید نیست. `schema.sql` یا فایل‌های تغییر RLS را برای این رفع خطا اجرا نکنید.

## پس از انتشار

- نسخهٔ تازهٔ `GolfAcademy_PRO.html` را **در همان مرورگر و گوشیِ دارای دادهٔ صف** باز کنید؛ می‌توان برای عبور از کش از `?v=cloud-size-20260926` استفاده کرد.
- در پنجرهٔ ☁️، **ارسال مجدد** را بزنید. فقط ACK موفق سرور، کلید را از صف حذف می‌کند.
- «تست اتصال» فقط خواندن را بررسی می‌کند و معیار ذخیره‌شدن این کلید نیست.
- اگر خطای دیگری ماند، نام کلید و متن همان خطا را بررسی کنید؛ داده‌های مرورگر را پاک نکنید.

## آزمون‌های بدون تماس با دیتابیس زنده

```sh
node source/e2e/cloud_e2e.mjs
node source/e2e/cloud_queue_e2e.mjs
# با esbuild نصب‌شده برای تبدیل TypeScript در محیط تست:
node source/e2e/ga_sync_size_e2e.cjs
```

تست تابع واقعی با SDK دیتابیسِ ساختگی انجام می‌شود: بستهٔ ۸۲۳ KiB، مرز دقیق ۲ MiB، ردکردن بیش از سقف، محتوای فارسی چندبایتی، CORS، و مسیرهای قدیمی بدون تغییر اطلاعات زنده بررسی می‌شوند.
